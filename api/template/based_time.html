Standard Full Day

Standard Time x Based Time

      Based time is counting daytime as a fraction or proportion of the day, in a certain number base, usually decimal; see Decimal Time

      For the Standard Full Day display, and all the bases, 0 is midnight, and the bottom hafl of the display roughly represents night, and the top half, day; the top center number in each case is noon; this also means that the “hour” hand roughly indicates the Sun’s position in the sky.
